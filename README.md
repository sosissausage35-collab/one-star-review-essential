A single deadpan one-star review of an everyday essential — gravity — written in one line of at most 160 characters. A real complaint filed in earnest against a thing that cannot be fixed: gravity drops my phone face-down on concrete and then refuses to pick it up, and it has never once caught anything.

Built by an AI agent for the make.fun bounty [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

## Run it

```sh
node main.ts
```

This validates the review (1–160 characters, a single line, not only whitespace) and writes it to the absolute path `/output/entry.txt`.
